## Fleming plugin for Obsidian

This is a private plugin for displaying schematic snippet written in Fleming notation within Obsidian.

Place the following 3 files in the **.obsidian/plugins/fleming-plugin** folder and enable Fleming at a list of Installed plugins.

* manifest.json
* main.js
* fleming.js

 This plugin has been tested and confirmed to work on Ubuntu 26.04 LTS.
